The Generative Estate holds build possibilities as specs rather than built code. Each spec is cheap potential; when you demand one, the wisp generates actual code from it, the kappa gate verifies the code against the spec's tests, and it only stands if it passes. A verified build is cached and content-addressed so identical demands never rebuild; a collapse that fails to verify is discarded and the spec stays possibility. A flaky-wisp toggle lets you watch a bad collapse get rejected.
